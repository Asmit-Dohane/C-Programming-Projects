# Simple Billing System
A Simple Billing System For Grocery Stores, This Programme Is For Grocery Stores To Add Item Details Like
<br>
Item Name, Item Quantity And Item Price, And This Program Is Calculate All Item Prices And Add Tax To Final Price And Display Bill, And This Programm Can Generate A Report On File.
<br>
Features:
1) Add Item Details
2) Calculate Totals
3) Add Tax
4) Display Bill
5) Generate Report

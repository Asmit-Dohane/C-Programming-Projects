# School Management System
Simple C Programming Mini Projects A Simple Student Management System For Teacher's. Teacher's Can Use This Program For Store Student Data, This Program Is Built With C Language, This Program Uses File Handling For Permanent Data Save After Closing The Program The Data Will Not Erase, And It Uses String, Loops etc. Features:

1) Add Student Data
2) Search Student Data
3) Display All Student Data
4) Save Student Data
5) Close
